# arthos-boot

Scripts do boot do Arch (Arthos-PC).

- `arruma-boot.sh`: tira o rEFInd, põe o GRUB primeiro e reaplica o tema gênese. Mostra um resumo no fim.
- `tema-boot.sh`: tema do GRUB em ASCII (cópia; a fonte é odrdk/dotfiles).
- `bluetooth.sh`: liga o Bluetooth, procura, você escolhe pelo número; pareia, confia e conecta.


Download sem login (repo público): `curl -O https://raw.githubusercontent.com/odrdk/arthos-boot/main/<script>.sh`
